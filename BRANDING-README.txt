ABUBAKAR PORTFOLIO LOGO & FAVICON

Brand identity inspired by the signature treatment in the public GitHub animated cover (assets/animated-cover.webp) and adapted to the portfolio's neutral-sage color palette. It is NOT a pixel-for-pixel extraction of the original handwritten signature, which is embedded in the animated banner.

Files:
- favicon.svg: crisp scalable browser favicon (preferred)
- favicon.ico: fallback browser favicon
- icon-180.png: Apple touch icon
- icon-192.png, icon-512.png: app/social use
- static/assets/abubakar-signature-logo-dark.png: signature-style transparent logo on light backgrounds
- static/assets/abubakar-signature-logo-light.png: on dark backgrounds
- static/assets/abubakar-mark.svg: standalone vector icon
- brand-preview.html: open locally to see assets

The portfolio HTML files already reference the new favicon and mark in the site navigation. The signature wordmark is displayed beneath the profile photo on the homepage.

Deploy instructions: Extract the ZIP, then upload all its contents to the root of your existing GitHub Pages repository. Replace older files.

The source signature is in this public GitHub banner: https://raw.githubusercontent.com/abubakar-maqsood/abubakar-maqsood/main/assets/animated-cover.webp
If exact signature tracing is desired, supply its original SVG/PNG or a cropped still image.
