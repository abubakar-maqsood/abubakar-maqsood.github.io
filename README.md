# Abubakar Portfolio — compact editorial edition

GitHub Pages-ready static portfolio. Inspired by the user-approved compact preview.

## Publish
1. Extract this ZIP.
2. In `abubakar-maqsood.github.io`, upload the **contents** of this extracted folder.
3. Keep `index.html` at repository root and preserve every `static/` and `projects/` folder.
4. Commit changes. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Design decisions
- Original GitHub handwritten signature is used only in the navigation.
- Duplicate signature below the photo has been removed.
- Photo is constrained to a compact framed size across screens.
- Warm cream, charcoal and sage-green color scheme, with optional dark mode.
- Academic claims and project status remain accurate; research questions are exploratory.
- Google Colab, GitHub, LinkedIn, Ayhan Co, CV, all project details remain available.

If the LinkedIn URL changes, replace `https://www.linkedin.com/in/abu-ba-kar/` in the HTML files.
